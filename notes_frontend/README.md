# Notes Frontend (Next.js)

Next.js web UI for the Personal Notes Organizer.

## Requirements

- Node.js 18+
- Backend running and reachable from the browser

## Environment

Set:

- `NEXT_PUBLIC_API_BASE` — base URL of the backend (example: `http://localhost:3001`)

You can copy `.env.example` to `.env.local` for local development.

## Run

```bash
npm install
npm run dev
```
